The dividing line

Capture, correlation, DQL querying and multi-step investigation are native to Dynatrace. Sentinel Ops calls them read-only and builds only the management layer on top — so the two never overlap.

What Sentinel Ops owns

  • Business context per agent — purpose, owner, criticality, expected outcomes
  • Budgets, cost baselines, SLOs and policy thresholds
  • Budget-exhaustion forecasts and release-risk scoring
  • Evidence-backed findings ranked by business impact
  • Cross-platform context from ServiceNow — services, changes, incidents
  • Verified optimization — apply a change, measure cost and quality against a baseline

What it never rebuilds

  • Telemetry capture and ingestion
  • Span correlation and distributed tracing
  • The DQL engine and Grail storage
  • Davis-style anomaly detection
  • A tracing or query interface
  • Any hard enforcement or auto-remediation

System architecture

A modular-monolith backend (Python / FastAPI) and a hand-built Next.js console. A single adapter boundary is the only code that talks to the outside world — Grail, ServiceNow and the optional LLM each sit behind one seam.

The eight-dimension model

An agent can be runtime-healthy yet financially inefficient, or expensive yet business-critical — so the dimensions stay separate. Five are assessed from live telemetry; three are reported honestly as out of scope for the PoC rather than faked green.

Task effectiveness

Design guarantees

The properties that make the output trustworthy — enforced in code, not left to convention.

Read-only against Dynatrace
The runtime data plane only queries Grail. The platform never writes telemetry or mutates observability data.
Evidence on every claim
Each finding carries the DQL text and the rows behind it. Nothing is asserted that cannot be re-run.
Deterministic decisions, optional LLM assistance
Findings come from deterministic detectors; the optional LLM is strictly additive and never in the critical decision path. Every judgment cites the telemetry behind it and records its confidence.
Stale data is never green
Telemetry older than the freshness window is reported as partially assessed with its age, never as healthy.
Coverage gaps shown, not faked
A missing measure reads "not instrumented". Unmapped agents read "partially assessed" — never a plausible zero.
One write, fully gated
Creating a ServiceNow incident needs explicit approval, respects source-of-truth ownership and blocks likely duplicates.
